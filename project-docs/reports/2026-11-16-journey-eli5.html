2쪽 · Ghost-ALICE가 뭐예요?

답장을 검사하는 문지기, 그리고 쪽지

쪽지(응답 경로)는 "이건 설명 / 이건 작업"이라는 표시예요. 예전 문지기는 쪽지가 없으면 답장을 멈췄어요.

5쪽 · 어떤 답장이 멈췄나

읽기만 한 답장은 거의 자동 실행에서 멈췄어요

읽기만읽기 + 기록 남김 다른 명령파일 고침기타 도구

자동 실행(claude -p) 351번, 대화형 작업 57번(11:32 기준).

6쪽 · 고친 것

7가지를 고쳤어요

예전 줄기에서는 새 테스트마다 "고치기 전 실패 → 고친 뒤 통과"를 확인했어요. 두 줄기 모두 고친 코드와 고치기 전 코드를 함께 돌려, 고쳐서 새로 생긴 실패가 없는지 봤어요.

7쪽 · 쪽지 문제를 푸는 4가지 방법

A·B는 만들었고, C는 팀이 정할 일

만듦A. 쉬운 쪽지한 줄로 쓰고, 문지기가 미리 알려 줘요
만듦B. 통과증자동 실행에서도 쪽지를 쓸 수 있어요
팀 결정C. 문지기가 대신대신 써 줘도 다음 검사에서 또 멈춰요. 규칙을 바꿔야 해요
비추천D. 그냥 통과기록이 사라져요
8쪽 · 깜짝 발견

최신 문지기는 이미 달라져 있었어요

최신 코드는 쪽지 없는 일반 답장을 막지 않아요. 그래서 A·B는 최신 코드로 옮기지 않았고, 작은 수리 4개만 옮겼어요.
